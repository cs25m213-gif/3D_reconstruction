Training signal

Maroon equations supervise the frame-utility and action blocks (2–3).

ADD candidate cg_ADD(c | S) = F(S ∪ {c}) − F(S)
SWAP occupant o for cg_SWAP(c, o | S) = F((S ∖ {o}) ∪ {c}) − F(S)
KEEP the current setg_KEEP(S) = 0

Measure the surface-score change after adding a candidate or replacing an occupant, reconstructing both alternatives with the same depth model.

S: retained frame set; c: candidate; o: replaced occupant. F: surface F-score from fusion/checks (block 5). Gains use the same depth version and reference.

What the selector is

  • Image encoder: ResNet18 → 384-d embedding, with an auxiliary image-degradation head.
  • Context: three tokens (map state, candidate, occupant) through a four-layer Transformer, width 256, 8 heads.
  • Decision: ADD head for an empty view bin, SWAP head for an occupied one; DINO similarity (cos ≥ 0.9) defines the bins.
  • Robustness: trained with motion blur, defocus, mixed degradation and frame gaps.

Keyboard: Space plays or pauses, arrow keys change step. All timings were measured on one GPU shared with another training job.
